Gemütskarussell Website
========================
Öffne index.html lokal im Browser.

Enthalten:
- 24 Rollen aus der hochgeladenen PDF
- Suche und Fraktionsfilter
- Klickbare Rollen-Details
- Dschinn-Spezialregeln von Seite 2
- Spieleraufteilung von Seite 2
- Original-PDF-Seiten als Referenz

Die Website ist komplett statisch und benötigt weder Datenbank noch Server.
Für die Veröffentlichung eignen sich z.B. GitHub Pages, Netlify oder Cloudflare Pages.
